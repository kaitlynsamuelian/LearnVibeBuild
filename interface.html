The six areas, one at a time

1

The Editor (the big middle area)

Where your files open and where you read and write code. This is the heart of the app — like the page of a document. Each open file gets a tab across the top.

2

The File Explorer (left sidebar)

A list of all the files and folders in your project. Click any file to open it. This is how you navigate your project, like a folder view on your computer.

3

The Activity Bar (far left icons)

Thin strip of icons to switch what the sidebar shows: Files, Search, Source Control (Git), and more.

4

The AI Chat / Agent panel (right)

Your conversation with the AI. Type a question or a task, pick a mode (Agent, Ask, Plan), and watch it respond. It can also pop out into a full-screen Agents Window. This is Cursor's signature feature — covered fully on the Features page.

5

The Terminal (bottom panel)

A place to type text commands that run programs — like starting your website or installing tools. Cursor's AI can even write and run these commands for you. New to terminals? See the glossary.

6

The Status Bar (very bottom strip)

A thin bar showing at-a-glance info: your current Git branch, error/warning counts, the file's language, and whether Cursor Tab is on. Handy signals, nothing you need to touch.

Two views of the same thing

The Agent panel vs. the "Agents Window"

This one confuses almost everyone at first. Cursor gives you the AI chat in two shapes — a small panel tucked beside your code, and a full-screen window. It's the same conversations either way; only the layout changes.

Agents Window command center

Click the "Agents Window" button (top-right) to open the same chats full-screen, with a history list on the left. The code editor is hidden — that's why it looks like ChatGPT.

Same AI, same conversations — just a bigger canvas. The list on the left is your chat history (like ChatGPT's), grouped by project. Use the full window to read long chats or juggle several agents at once; use the docked panel when you're heads-down editing code. Switch back anytime by closing the window or clicking into your file.

Don't confuse it with the blue send button. The small blue arrow at the bottom of the chat box just sends your message. The Agents Window button lives at the top-right and opens the full-screen view.

A few things that trip up newcomers

Small clarifications that save a lot of confusion.

Panels can be hidden or resized. Don't see the sidebar or terminal? They can be toggled open and closed. Drag the borders between panels to resize them to your liking.

The Command Palette is your search box for the whole app. Press Cmd/Ctrl + Shift + P to search every command by name. Forgot how to do something? Start here.

Themes and font sizes are adjustable. Prefer a light background or bigger text? Open Settings and make it comfortable. This whole site has a light/dark toggle in the top-right, too.

You can't "break" anything by clicking around. Exploring panels is safe. The only things that change your files are edits you accept — and those can always be undone.
