# Product

## Platform

web

## Stack

static HTML, CSS, and a little JavaScript. No build step. Matches the rest of the Learn, Vibe, Build hub. [inferred from repo convention and the user's request to land this as a hub artifact]

## Users

Kaitlyn Samuelian and classmates in Learn, Vibe, Build (ATLAS, CU Boulder) comparing what a website looks like without a design skill (Test website A) versus with Impeccable (Test website B). A visitor opens the gallery to see kinds of flowers, one bloom at a time.

## Product Purpose

A small site about different types of flowers. A home screen, then a scrolling gallery: each screen is one flower and a short description. Success is that a visitor can name the types and tell Test B apart from Test A as a design-skill A/B.

## Positioning

Same flower job as Test website A, rebuilt under Impeccable so the visual world is not the charcoal SVG gallery already on the hub.

## Operating Context

Lives at `test-b/` on the class hub (`index.html`). Linked as artifact 11. Test website A at `test-a/` stays unchanged. Local preview: `python3 serve.py` on 127.0.0.1:4321. Back link to `../index.html`.

## Capabilities and Constraints

- Home plus a scrolling gallery of flower types with a description on each screen
- Same eight flowers and the same informal facts as Test A: rose, sunflower, lavender, peony, tulip, poppy, lily, hydrangea
- Static files only
- Do not delete Test A, other artifacts, or vault research
- Do not use em dashes
- Distinct theme from neighbors (including Test A's charcoal garden)

## Brand Commitments

- Title on the hub: Test website B
- Subject: kinds of flowers
- Voice: beginner-first, plain, the same informal register as Test A copy
- No encyclopedia tone

## Evidence on Hand

Test A copy and structure at `test-a/index.html` (home lede plus eight flower descriptions with Latin names). Reuse those facts. Do not invent commercial claims, growers, prices, or scientific citations.

## Product Principles

- One flower, one screen, a short description
- Fair A/B: same content job as Test A, different visual world
- Stay a static class artifact, not a shop or a plant ID app
- Let the blooms lead; chrome recedes

## Accessibility & Inclusion

Keyboard-reachable gallery navigation and body text contrast at least 4.5:1. [inferred from class-hub practice]
