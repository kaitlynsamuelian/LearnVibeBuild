Upload the PDF (or paste the text). This page reads it in your browser, then splits what’s done, what’s in progress, and what’s still open — and you can ask it questions. It is not an advisor and it does not replace Buff Portal.

or click to choose a file. Nothing is uploaded to a server — it stays on this computer.

1. Get a text PDF

In CU’s degree audit, open Advanced Settings and set Format to PDF before you run it. That extracts much better than a screenshot.

2. Keep it private

Audits have your name and student ID. This tool doesn’t send the file anywhere unless you turn on an optional API key.

3. Trust, but verify

Green checks and red X’s sometimes vanish in PDF text. Always confirm leftovers with a human advisor before you change a plan.
