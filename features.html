// Feature 01

Tab — autocomplete that predicts your next move

As you type, Cursor shows a faded preview of what it thinks you'll write next. Press Tab to accept it instantly. It's the single feature you'll use most, and it works quietly in the background.

Unlike plain autocomplete, Cursor's Tab can suggest multi-line edits and even predict the next place you'll want to change, jumping you there. Ignore a suggestion by just continuing to type, or press Esc.

  • Accept: press Tab
  • Reject: press Esc or keep typing
  • No chat required — it just appears as you work

// Feature 02

Inline Edit — change one exact spot

Select a chunk of code (or click an empty line), then press Cmd/Ctrl + K. A little box appears where you describe the change you want, right there in the file.

It's perfect for focused tweaks: "rename this variable," "add error handling here," "translate these comments to Spanish." Cursor shows the change as a diff (old vs. new) that you accept or reject.

Use Inline Edit when you know exactly which lines should change. For bigger, multi-file jobs, use the Agent instead.

// Feature 03 — the star of the show

Agent — describe a goal, it does the work

The Agent lives in the chat panel. You give it a task in plain English and it can read your files, plan an approach, edit multiple files, run terminal commands, and check its own work — looping until the job is done.

It's like handing a task to a capable teammate. You stay in charge: the Agent proposes changes and you review them. It'll often ask before doing anything risky.

  • Great for real tasks: "add a contact form," "fix this bug," "add dark mode."
  • Can run commands (with your permission) to install things or start your app.
  • Shows every change as a reviewable diff before it's permanent.

// Same AI, two layouts

The docked panel vs. the "Agents Window"

Cursor shows your AI chats in two shapes, and mixing them up is one of the most common early "wait, what happened?" moments. They're the same conversations — only the layout differs.

Docked panel everyday

A strip beside your code, so you can chat while watching files change. Best for building and editing. Toggle with Cmd/Ctrl + I.

Agents Window full screen

The "Agents Window" button (top-right) opens the same chats full-screen with a history list on the left. Editor hidden — that's why it looks like ChatGPT.

Use the full window to read long chats or run several agents at once; use the docked panel when you're heads-down in code. There's a fuller, illustrated walkthrough on The Interface page.

// Feature 04

Ask — a read-only Q&A about your code

Ask mode is for understanding, not changing. It answers questions about your project without touching a single file. Perfect when you're curious or cautious.

Use it to learn: "What does this function do?", "Where is the login handled?", "Explain this error message to me like I'm new." It's the safest way to explore.

Ask never edits. If you want it to actually make the change it just described, switch to Agent mode and ask again.

// Feature 05

Plan — think before building

For anything bigger than a quick change, Plan mode is your friend. Instead of diving straight in, Cursor first writes out a plan — the steps it intends to take — so you can review and adjust the approach before any code is written.

You read the plan, tweak it if needed, and then let the Agent carry it out. It dramatically reduces surprises on non-trivial tasks and helps you learn how the work breaks down.

Rule of thumb: if a task touches several files or you're not sure how it should work, start in Plan mode. It's the recommended path for anything non-trivial.

You can switch modes mid-conversation. Start in Ask to understand, then flip to Agent to make the change. Cursor also supports custom modes (powered by Skills) for advanced workflows.

Context: how Cursor knows about your project

"Context" just means the information the AI can see when it answers. The more relevant context, the better the result. Cursor gives you easy ways to point it at exactly the right things.

The @ symbol

Type @ in the chat to attach specific context. A menu pops up so you can pick exactly what the AI should look at.

Codebase indexing

Cursor quietly builds a searchable map of your project so it can find relevant files on its own — even ones you didn't mention.

The exact list of @ options changes over time as Cursor evolves. When in doubt, type @ and see what the menu offers — or check the official docs.

// Under the hood

Models — the "brain" you can swap

The intelligence behind Cursor comes from large AI models (the same family of technology as ChatGPT and Claude). Cursor lets you pick which model handles your request from a dropdown in the chat.

Different models have different strengths — some are faster, some are more thorough. As a beginner you can happily leave it on the default; experiment later once you're comfortable.

The available models change frequently. The default is a solid all-rounder — no need to overthink it at first.

Reviewing, accepting & undoing changes

The golden rule of Cursor: the AI suggests, you decide. Nothing is permanent until you accept it, and even then you can undo.

Read the diff

Changes appear as green (added) and red (removed) lines. Skim them — you don't need to understand every line to accept obvious improvements.

Accept or reject

Keep what you like, reject what you don't — per change or all at once. If something looks off, reject it and ask for a different approach.

Undo with checkpoints

Cursor keeps checkpoints so you can roll back to how things were before a request. Handy for "actually, never mind."

The Agent may ask permission to run a command. When it wants to do something in the terminal (install a tool, start your app), it shows the exact command and a Run button. Read it, and if it looks reasonable, allow it. This "ask first" step is a safety feature — you can also turn on auto-run later once you trust the flow.

Checkpoints are a convenience, not a safety net. For real projects, also learn basic Git — the standard way to save and restore versions of your work. It's the professional backup system.

Seeing red squiggly underlines? Those are linter warnings pointing at likely mistakes — not the app breaking. Hover to read the message, or just tell the Agent "fix the errors in this file" and it'll usually sort them out.
