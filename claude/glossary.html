Reference

Glossary & FAQ

New tools bring new words. Here's every term you'll meet, each in one plain sentence — plus answers to the questions newcomers ask most.

Glossary

AI Artificial Intelligence

Software that can do things usually needing human intelligence — understanding language, answering questions, writing, and reasoning.

Claude

Anthropic's AI assistant. Also the umbrella name for the assistant, Claude Code, and the underlying models.

Anthropic

The AI safety company that builds Claude, with a focus on making AI helpful, honest, and harmless.

Claude Code

Anthropic's agentic coding tool. It runs mostly in the terminal and can read, edit, and run your project's files to complete tasks.

LLM Large Language Model

The "brain" behind AI assistants — trained on huge amounts of text to understand and generate human-like language, including code.

Model

A specific AI brain you can pick, balancing capability, speed, and cost. Claude's tiers are Haiku, Sonnet, Opus, and Fable.

Prompt

The message you send the AI. Clearer prompts get better answers.

Context

The information the AI can see when answering — your message, attached files, the conversation so far. More relevant context, better results.

Context window

The maximum amount of information the model can hold in mind at once. Very large inputs may not all fit.

Token

A small chunk of text (part of a word) that models read and count. Usage and limits are often measured in tokens.

Agent / Agentic

An AI that can take a series of actions toward a goal — reading, editing, running commands — not just replying. Claude Code is agentic.

Agentic loop

The cycle an agent repeats: gather context → decide a step → act → check the result → repeat, until the task is done.

Terminal / Command line

A text window where you type commands to run programs. Claude Code mainly lives here — and can write the commands for you.

Command

A single instruction you type into the terminal, like npm install, telling the computer to do something.

CLI Command-Line Interface

A tool you operate by typing commands rather than clicking. Claude Code is a CLI tool.

Code / Source code

The written instructions that tell a computer what to do — just text, organized into files.

File & Folder

A file holds a piece of your project; a folder groups related files. Your project is one main folder.

Repository (repo)

A project's folder, especially when its history is tracked by Git. Often shortened to "repo."

Git

A system that saves snapshots of your project over time, so you can track changes, undo mistakes, and collaborate.

GitHub

A popular website for storing Git repositories online and working with others. You can tag @claude there to get help.

Commit

A saved snapshot in Git, with a short note describing what changed.

Pull request (PR)

A proposal to add your changes into a shared project, so others can review before merging.

CLAUDE.md

A plain text "memory" file in your project. Claude Code reads it each session for standing instructions — structure, commands, and your preferences.

Slash command

A shortcut you run by typing /name in Claude Code, such as /clear or /model.

Skill

A packaged set of instructions for doing a specific multi-step task consistently — the recommended way to save reusable workflows.

Subagent

A helper agent Claude Code spins up for a side task in its own workspace, working in parallel and reporting back.

Hook

An automatic action that fires at a set moment in Claude Code's lifecycle — like running the formatter after every file edit.

MCP Model Context Protocol

A standard way to connect Claude to outside tools and data (GitHub, databases, browsers) so it can use them. "Apps for your agent."

API Application Programming Interface

A way for programs to talk to each other. Developers use Anthropic's API to build Claude into their own apps.

Agent SDK

A developer toolkit for building your own agents on the same engine that powers Claude Code.

Project (in Claude)

A place to group related chats and reference files so Claude keeps them in mind across conversations.

Hallucination

When an AI states something incorrect or made-up with confidence. It's why you always double-check important answers.

Prompt injection

A trick where hidden instructions in a document or website try to make the AI misbehave. A reason to be careful with untrusted content.

Bug

A mistake in code that makes a program behave incorrectly. "Debugging" is finding and fixing bugs.

Frequently asked questions

The things newcomers wonder about most.

Claude is the assistant you chat with (at claude.ai or in the apps). Claude Code is a separate tool that puts Claude to work on your computer — reading, editing, and running your files to build software. Same underlying intelligence, different jobs. See What is Claude.

They're similar kinds of product — AI assistants you chat with — but made by different companies. Claude is from Anthropic; ChatGPT is from OpenAI. Claude is often praised for careful reasoning, writing quality, and coding. Many people try both and pick their favorite per task.

Not for Claude the assistant — it's for everyone, no coding involved. Claude Code is aimed at building software, but you can describe what you want in plain English and let it write the code. It's actually a great way to learn coding, since you can ask it to explain everything.

There's a free plan with a daily usage limit, plus paid plans (Pro, Max, Team) with more usage, better models, and features like Projects. Prices and limits change, so check claude.com/pricing for current details.

Start with Sonnet — it's the balanced default and handles most things well. Step up to Opus or Fable for the hardest tasks, or down to Haiku for speed and low cost. As a beginner, the default is a great choice.

By default it asks permission before editing files or running commands. Read what it proposes, then approve or deny. For extra safety, use Git so you can undo anything. Keep the default "ask me" behavior while you're learning.

Yes. Like all AI, Claude can be wrong or occasionally "make things up" (a hallucination). It's very capable, but not infallible — double-check anything important, and ask it to show its reasoning or sources when it matters.

Anthropic publishes privacy and data-use policies, and business/enterprise plans have stricter data handling. If you're working with sensitive material, review the current policy at anthropic.com and your plan's settings to understand exactly what applies.

Cursor is an AI code editor (a full app with the AI built into it). Claude Code is an AI coding tool that lives mainly in the terminal. They overlap, and interestingly Cursor can even use Claude's models. If you use Cursor, see the companion Learn Cursor guide.

Ask Claude itself — it's great at explaining errors and concepts. For official details, read the Claude documentation and the Claude Code docs.
