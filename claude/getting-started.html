Getting Started

Two easy beginnings. First, chat with Claude on the web — that takes about a minute. Then, when you're curious about hands-on building, install Claude Code.

Part 1 — Claude (the assistant). Nothing to install. Everything happens in your web browser. Perfect for absolute beginners.

Create your account

Go to claude.ai

Open claude.ai in your browser. You can sign up with a Google account or an email address. There's also a Claude app for Mac, Windows, iPhone, and Android if you prefer.

Verify and sign in

Confirm your email if asked, then you're in. You'll land on a simple screen with a big text box — that's where the conversation happens.

That's it — you're ready

No configuration, no jargon. The free plan lets you start chatting right away.

claude.ai
YouI'm new to all this. In 3 sentences, what can you help me with?
ClaudeHappily! I can help you write and edit anything, explain tricky topics in plain language, and think through problems or plans with you. Attach a document and I'll summarize or answer questions about it. Just ask in your own words — no special phrasing needed.

Send your first message

Click the text box, type a question in plain English, and press Enter. Try one of these to get a feel for it:

  • "Explain how the internet works, simply."
  • "Help me write a friendly email asking for a refund."
  • "Give me a 7-day beginner plan to learn guitar."

Not happy with a reply? Just say so — "make it shorter," "more formal," "explain that last part." It's a conversation, so keep refining.

Free vs. paid, in plain terms

Free

Try it out

Chat with Claude with a daily usage limit, on the default model. Plenty to learn the ropes and handle everyday questions.

Pro

Everyday power user

More usage, access to more capable models, and features like Projects. A common pick once you're hooked. Includes some Claude Code use.

Max / Team

Heavy & shared use

The highest usage limits and top models (Opus by default on Max), plus team features. For people who lean on Claude all day.

Plan names, prices, and limits change over time. For today's exact details, see claude.com/pricing.

Part 2 — Claude Code (optional, for building software). This one lives in the terminal. Totally skippable if you just want to chat — come back when you're curious about coding.

Install Claude Code

Claude Code installs with a single command you paste into your terminal. Pick your system below.

macOS & Linux

Terminal
$ curl -fsSL https://claude.ai/install.sh | bash

Windows (PowerShell)

PowerShell
> irm https://claude.ai/install.ps1 | iex

What's a terminal? It's a text window where you type commands. On Mac it's the "Terminal" app; on Windows, "PowerShell." New to it? Our glossary explains it, and Claude itself can walk you through opening it.

Run the install command

Open your terminal, paste the line for your system, and press Enter. It downloads and sets up Claude Code in a minute or two.

Go to your project folder

Use cd to move into the folder you want to work in — for example cd my-project. New to this? Ask Claude (the assistant) "how do I navigate to a folder in the terminal?"

Start it by typing claude

Run claude and press Enter. The first time, it walks you through signing in with your Claude account. Then you get a prompt where you can talk to it.

Only install from official claude.ai / Anthropic sources. Install commands can change — the current ones live in the Claude Code docs.

Try your first Claude Code task

Once you see the > prompt, just describe what you want in plain English — same as chatting, but now it can act on your files.

A gentle first request:

"Explain what this project does, then create a simple README file describing it."

Claude Code will look around, tell you what it found, and ask before making changes. You approve, and it does the work. That review-and-approve rhythm is the heart of using it safely.
