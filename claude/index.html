For people brand-new to AI

Meet Claude — and Claude Code.

Claude is a friendly, thoughtful AI assistant made by Anthropic. Claude Code is its coding sidekick that lives in your terminal. This is a calm, plain-English guide to both — what they are, how they differ, and how to actually use them, even if you've never touched AI before.

Start from the beginning Claude vs. Claude Code
First, the big picture

Two related things with similar names

Almost everyone mixes these up at first. Here's the clean distinction — the rest of the site builds on it.

Claude

The AI assistant you chat with — on the web at claude.ai, in a desktop or phone app. Ask questions, write, brainstorm, summarize, analyze documents, and more. No coding required.

Talk to it like a person

Claude Code

A tool that puts Claude to work on your computer — mostly in the terminal. It can read and edit your files, run commands, and build software for you. Powered by the same Claude.

Claude that takes action

One brain, two doorways. Both are powered by Anthropic's Claude AI models. Claude (the app) is for conversation; Claude Code is for hands-on building. You can start with either.

Why people love Claude

A capable assistant with a thoughtful streak

Claude is known for being helpful, careful, and good at longer, more nuanced tasks. A few things it does well:

Read & write

Summarize long documents, draft emails and essays, explain hard topics simply, translate, and edit your writing.

Think & analyze

Work through problems step by step, compare options, analyze data and spreadsheets, and reason about tricky questions.

Build software

Write, explain, and fix code — from a tiny script to a whole app — especially through Claude Code, its agentic coding tool.
