Claude Code Shortcuts

These are for Claude Code (the terminal tool) — not the claude.ai chat. You don't need to memorize them; a handful quickly become second nature.

Two small notes. Meta means Option on Mac and Alt on Windows/Linux. And everything here is customizable — you can remap keys in ~/.claude/keybindings.json, and type /help anytime to see current commands.

Prompt prefixes (type these first)

The character you start a line with changes what happens. These are the fastest way to steer Claude Code.

/  Slash command

Run a built-in command like /clear, /model, or /help.

@  Mention a file

Point Claude at a specific file or folder, e.g. @index.html, so it reads exactly that.

#  Save to memory

Start a line with # to add a note to your project's CLAUDE.md so Claude remembers it.

!  Bash mode

Run a raw terminal command yourself, e.g. !ls, without leaving Claude Code.

When Claude asks permission

ActionKeys
ApproveY  or  Enter
DeclineN  or  Esc
Move between options↑ / ↓
See an explanation of the commandCtrl + E

Start with just three: Enter to send, Shift + Tab to switch modes (especially into plan mode), and Esc to stop Claude if it's heading the wrong way. The rest will come naturally.

Claude Code updates often, so a key here and there may change. The current reference lives in the Claude Code keybindings docs.
