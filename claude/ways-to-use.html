Chapter 4

Ways to Use Claude

Claude meets you where you are — a browser tab, an app on your phone, your code editor, or automated behind the scenes. Here's every doorway, and who each is for.

Talking with Claude (the assistant)

The web (claude.ai)

The simplest way in. Nothing to install — just open claude.ai and chat. Best for beginners.

Desktop app

A dedicated Claude app for Mac and Windows — the same chat, always a click away, with handy shortcuts.

Mobile app

Claude on iPhone and Android for questions on the go. Snap a photo, dictate, or type wherever you are.

Projects

On paid plans, Projects let you group chats and upload reference material (documents, notes) that Claude keeps in mind across many conversations. Great for ongoing work on one topic.

Analyze files & images

Attach PDFs, spreadsheets, images, and more in any chat. Claude can read, summarize, and answer questions about them.

Putting Claude to work (Claude Code)

Terminal

The classic way to run Claude Code: type claude in your terminal and go. Covered in the Claude Code chapter.

Inside your code editor

Claude Code has extensions for popular editors like VS Code, so it works right beside your files instead of a separate window.

On the web

Claude Code can also run in the browser and hand off tasks that continue in the background — useful away from your main computer.

GitHub & CI/CD

Tag @claude on a GitHub issue or pull request to have it make changes, or run it automatically as part of your team's pipeline. A team-oriented power feature.

The API

Developers can build Claude directly into their own apps and websites through Anthropic's API — the plumbing behind many AI products.

Agent SDK

A toolkit for building your own AI agents on the same engine that powers Claude Code. Advanced, but good to know it exists.
