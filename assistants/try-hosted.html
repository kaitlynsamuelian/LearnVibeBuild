Chapter 2 · no VPS

Try a hosted one this afternoon

If you want the “it texts like a person” feeling without installing Node, start here. Confirm the official site still says what this page says — these products move weekly.

Path A — Meta Muse (US, easiest closed door)

Meta shipped Muse in September 2026 as a personal agent: chat in the Muse app or WhatsApp, keep working after you close the app, ask before sensitive stuff (send email, buy something). It runs on Meta’s “Secure VM,” not on your laptop.

  1. You need to be in the United States and old enough for the product (Meta’s rollout is 18+). If you’re not, skip to Path B. Don’t VPN-and-hope for a class demo.
  2. Open muse.ai or the iOS / Android app. WhatsApp is the “it lives in a chat I already have” path.
  3. Give it one boring job: “What’s on my calendar tomorrow?” or “Draft a text I will send myself.” Do not connect checkout on the first sitting.
  4. When it asks to connect Gmail / Instagram / payments: start with read-only if that’s an option. Muse’s own post says you pick how much access each app gets, and it should ask before sending or buying. Use that.

Don’t repeat the ad copy. Meta called it the first personal agent “for everyone.” Other agents existed. Muse is the polished, US-consumer, WhatsApp-shaped one from a company that already has your social graph. Free tier plus paid plans (figures change — check their site). “Confidential VM” (even Meta can’t read it) was promised later, not day one.

Path B — a hosted bot in Telegram (or iMessage)

If Muse isn’t in your country, or you refuse Meta, there are products that are “just text this username.” Names churn. As of this writing, examples include folk (iMessage / Telegram / WhatsApp) and Telegram-first bots like Overfolder. Search the current class tools page too — Meta listed Muse there for a reason.

  1. Pick one with a real privacy page. New bots appear every week. Treat unknown @handles as strangers.
  2. Message it something you would not mind a company storing.
  3. Same permission rule: reminders first, inbox send later.
