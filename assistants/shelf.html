Reference

The tool shelf

Not every bot on Twitter. The ones this guide is actually about, plus a few cousins so you can place them.

Hosted personal agents

Muse

Meta. US app / muse.ai / WhatsApp. Consumer “do the task” agent. Closed. ai.meta.com/muse

folk (and similar)

Lives in iMessage / Telegram / WhatsApp. Hosted cloud computer. Example of the “text it like a person” product. folk.com

You-run-it gateways

Hermes Agent

Nous Research. CLI, desktop, many chat apps. Skills + memory + cron. Not the same thing as “Hermes the model,” though same lab. docs · GitHub

OpenClaw

Self-hosted gateway + assistant. MIT. Nonprofit steward. openclaw.ai

Related, but different jobs

Cursor / Claude Code

Coding agents. See Learn Cursor and Learn Claude. You can point Hermes at Claude. That’s still a personal-assistant harness.

Ollama + HuggingChat

Brains and browser chats. Not assistants until something remembers you and texts you. Learn Open Source.

Siri / Google / Alexa

Phone assistants. They talk. They do not (yet) look like Muse/Hermes/OpenClaw. Don’t pretend this guide covers them.
