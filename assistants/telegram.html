Chapter 4

Telegram is a doorway, not a brand of AI

You can text an agent the way you text a roommate. The brain is still Claude or GPT or Muse Spark behind the username.

Three ways a “Telegram agent” happens

1. You own the gateway

Hermes gateway setup or OpenClaw channel plugin. You create a bot with Telegram’s BotFather, paste the token into your machine. Best control. Most setup.

2. Someone hosts it

You message @SomeBot. They run the server. Faster. You’re trusting a startup with whatever you type and whatever accounts you connect.

3. It’s just ChatGPT with a Telegram skin

No memory, no inbox, no “it texted me first.” Fine for jokes. Not a personal assistant. Don’t pay “agent” prices for this.

If you wire Hermes / OpenClaw to Telegram

  1. Talk to @BotFather in Telegram. Make a bot. Copy the token like a password.
  2. Put that token only in the official Hermes / OpenClaw setup. Not in a random GitHub gist.
  3. Turn on an allowlist of your account (and nobody else) before you use it in a group chat.
  4. Assume group chats will try to jailbreak or spend your API money. Don’t add the bot to a 200-person chat for fun.

WhatsApp / iMessage are the same idea. Muse uses WhatsApp because Meta owns it. OpenClaw and folk list iMessage. The risk is identical: the chat app is a pipe. Who runs the agent on the other end is the question.
