Glossary & FAQ

The words this guide uses, plus the questions after someone DMs a bot your Gmail.

Glossary

Personal assistant / personal agent

An AI setup meant to know you over time and take actions (remind, email, book), usually through a chat app — not only answer questions in a browser tab.

Gateway

The always-on program that holds sessions, tools, and connections to Telegram/WhatsApp/etc. Hermes and OpenClaw both have one.

Channel

Where you talk to it: Telegram, WhatsApp, Discord, iMessage, a custom app. Not the intelligence.

Muse

Meta’s hosted personal agent (US, 2026). App, muse.ai, WhatsApp. Closed. Powered by Muse Spark.

Hermes Agent

Open-source agent from Nous Research. CLI/desktop + messaging gateway. Different from “Hermes” the model family, same lab.

OpenClaw

Open-source self-hosted assistant/gateway (MIT, foundation-stewarded). Lobster branding. Not an OpenAI product.

Allowlist

A list of people (phone numbers, Telegram ids) who are allowed to talk to your bot. Turn this on before the username leaks.

BotFather

Telegram’s official bot for creating bot tokens. The token is a password.

Sentinel (Muse)

Meta’s name for a second process that has to approve Muse before it talks to the internet. Marketing word — still their cloud.

Cron / scheduled job

A task that runs later (“brief me at 8am”). Needs a machine that is actually on.

Skill

A saved how-to (often a SKILL.md) the agent loads for a specific job. Hermes uses these a lot.

Hosted vs self-hosted

Their computer vs yours. Hosted is easier. Self-hosted is more work and still often calls a hosted model.
