The honest version

ChatGPT answers. These try to act.

Cursor writes code. Claude talks in a tab. A personal assistant is supposed to live where you already message people, keep a memory of you, and take actions — calendar, inbox, a booking — after you say yes.

Two doors. Hosted (Muse, some Telegram bots): easy, someone else’s computer. Self-hosted (Hermes, OpenClaw): you run the gateway. Telegram is usually the hallway, not the product.

Three ways in, in order

1. Hosted

Meta Muse if you’re in the US. Or a Telegram-hosted bot. No VPS. They see the chat.

2. Your machine

Hermes Agent or OpenClaw. Install, one chat that works, then plug in Telegram.

3. The chat apps

Telegram, WhatsApp, Discord — doorways. Lock who can message the bot.
