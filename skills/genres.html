A catalog, not a dump on the home page

Other genres besides a look.

Design-look skills got their own spotlight on home. These are the other kinds people actually keep: voice, shipping, tests, review, git, research, debugging, docs, accessibility, and “how this repo works.”

A genre is a job shape, not a brand name. You will not find an official Cursor skill called “brutalist campus flyer.” You will find (and write) skills that look like these buckets. Named packs with install steps: Existing skills (Impeccable is there).

Voice

Sound like a person

Rewrite in your words. Keep a sounding-board tone. Format an assignment without brochure-speak. Brand voice for a studio, not a logo.

When: you keep pasting “write it like I talk.” Find: homemade, or a team’s writing skill. This class already has a Builder starter for sounding-board notes.

Ship

Deploy and verify

The official textbook example: run tests, build, deploy to staging, hit the health check. A procedure with a beginning, middle, and “did it actually go up.”

When: shipping is more than one command. Find: Cursor’s deploy-app example in the docs; company plugins often bundle this.

Tests

Tests and TDD

Write tests the way this repo writes them. Red, green, refactor. Cursor even uses TDD as a Custom Mode example (beaker icon, green badge).

When: “add tests” always needs the same setup. Find: project skills next to the test folder; some GitHub lists file these under workflow.

Review

Review and security

A careful pass: bugs, regressions, “did we leak a secret.” Cursor already ships /review, /review-bugbot, and /review-security. People still write homemade ones with their own checklist.

When: before you call it done, or before a PR. Find: built-in first, then team review skills.

Git

PRs, splits, commit talk

Draft the PR. Split a monster diff. Conventional commits. Cursor’s /split-to-prs and /autopilot live here. Homemade cousins handle “how we title PRs.”

When: the git part is the job. Find: built-ins, then shipping plugins.

Research

Notes, critique, synthesis

Turn a desk crit, a PDF dump, or a pile of links into something you can sit with. Separate what was said from what you inferred. Do not lock a product.

When: the input is messy and the output should stay honest. Find: usually homemade. This class’s critique starter belongs here.

Debug

A specific tool, on purpose

Cursor’s own nested-skill example is literally “debugging with Datadog MCP.” The genre is: how we investigate in this stack, with these dashboards, not generic “try console.log.”

When: the tool has a ritual. Find: vendor skills (Sentry, Datadog, and similar) on GitHub lists and plugins.

Docs

Docs people will actually read

CHANGELOG format. README for a new artifact. API notes. “Write the help page in this outline.” Different from voice: this is structure, not personality.

When: every new thing needs the same skeleton. Find: project skills; some public “docs” skills on awesome lists.

Access

Accessibility pass

Contrast, labels, keyboard, reduced motion, alt text. A checklist skill, not “make it pretty.” Pairs with a design-look skill instead of replacing it.

When: before you show the work. Find: frontend skill lists; or write a short class one for static HTML.

Repo

How this place works

The local cousin of a design system: hub tiles, folder layout, no deleting research, python3 serve.py on 4321. You already have /learn-vibe-artifact. Companies keep deploy-web next to apps/web/ the same way.

When: the conventions are this project’s, not the internet’s. Find: in the repo. That is the point.
