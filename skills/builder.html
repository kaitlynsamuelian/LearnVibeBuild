Skill Builder

This does not install a skill. It writes the markdown. You still save the file in a folder whose name matches name.

Where to put the download. Project: .cursor/skills/your-name/SKILL.md. Personal: ~/.cursor/skills/your-name/SKILL.md. Then type /your-name in Agent chat. Reloading the window can help if it does not appear right away.

Starters:

Lowercase, numbers, hyphens. Must match the folder name.

This is the line Agent uses to decide relevance.

Leave blank if it should be available no matter which files are open.
