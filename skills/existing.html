The one you named

Impeccable

Paul Bakaus’s design skill pack. It is meant to make the agent better at real UI, not default “AI slop.” It is based on Anthropic’s frontend-design skill (Apache 2.0). Docs say it installs as one skill, /impeccable, with commands hanging off that (init / teach, craft, and others). Confirm the current command list on their site. It changes.

  • Site: impeccable.style · start here for current steps
  • Repo: github.com/pbakaus/impeccable
  • Install (their recommended): from the project root run npx impeccable install. It should detect Cursor and write into .cursor/skills/ (or ask project vs global). Reload Cursor.
  • Use: Agent chat, type /impeccable. Their getting-started flow is often /impeccable init (or teach) once, so the project has design context, then use it when you build UI.
  • Did it work? Customize → Skills, and / should show impeccable.

For the A/B compare: Impeccable’s description is written to fire on “build a page / website.” If you install it before the no-skill run, Agent might use it anyway. Do the without chat first, then install, then the with chat. Or keep using this repo’s slash-only /website-look for a cleaner control.

The original look pack

Anthropic frontend-design

The well-known “distinctive UI, not generic AI” skill. Impeccable cites this as its base. Lives in anthropics/skills as a folder named frontend-design.

Install: copy that folder to .cursor/skills/frontend-design/ or ~/.cursor/skills/frontend-design/. Cursor also reads .claude/skills/ if you already have it there.

Use: /frontend-design in Agent chat, then ask it to build or restyle the page.

This class repo

/website-look

A small slash-only design skill already in this project, for the compare experiment. It will not auto-run when you say “make a website.” That is the point.

Use: /website-look then the burrito-cart prompt on Compare. Use Impeccable in Chat B instead if you want the real-world pack.

Places to hunt more named skills

Lists go stale. Open the repo, read the SKILL.md, then copy or install. Treat a stranger’s skill like a stranger’s script.

Place What you’ll find
awesome-agent-skills Huge curated list (Anthropic, Vercel, Figma, Stripe, community). Search “frontend” or “design.”
awesome-frontend-skills Frontend-only. This is where Impeccable and other look/UI packs get linked with install one-liners.
cursor.com/marketplace Official Cursor plugins. Skills can arrive inside a plugin. Reviewed listings.
cursor.directory Community plugins and MCP. Cursor’s own docs point here for unofficial stuff.
agentskills.io The open skill format. Not a store. Explains why a Claude folder often works in Cursor.
anthropics/skills Official Anthropic examples beyond frontend-design (docs, pdf, etc.). Copy the folder you want.

Simple install if there is no CLI. Copy the skill folder (the one that contains SKILL.md) into .cursor/skills/the-name/. Reload. Type /the-name. Never drop it in ~/.cursor/skills-cursor/.
