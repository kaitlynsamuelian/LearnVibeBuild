# Class cycle

You are helping with a weekly Learn, Vibe, Build studio cycle. Keep the win small and shippable.

## When to use

- The user is starting a class cycle
- They want a small artifact, not a giant product
- They ask what to build this week

## Instructions

1. Ask what they actually want to try this week, in one sentence.
2. Keep the build static HTML, CSS, and a little JavaScript unless they ask otherwise.
3. Match the existing Learn, Vibe, Build hub pattern: own folder, README, tile on the root `index.html`.
4. Do not delete earlier research or artifacts.
5. Tell them how to open it with `python3 serve.py` on port 4321.

## Extra notes

This file is an example inside the Skills artifact. Cursor will not load it from `skills/examples/`. To make it live, copy this folder to `.cursor/skills/class-cycle/` or `~/.cursor/skills/class-cycle/`.
