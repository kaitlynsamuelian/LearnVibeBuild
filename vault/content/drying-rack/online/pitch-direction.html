Working notes from the ATLAS 4000 draft pitch, late September 2026. Early concept. Not locked.

The question

How can one drying system adapt to different laundry loads and living spaces, instead of requiring several different racks?

What “adaptable” can mean

  • Capacity = how much
  • Shape / geometry = what form
  • Attachments = what function
  • Installation = where / how it is supported

First concept we are showing

Installation + geometry. Not attachments, unless later research says we need them.

One core rack. Different spaces. Different configurations. Interchangeable installation modules and a reconfigurable drying frame.

Mockup prompt that worked

One pale-wood and matte-metal frame, four mounts only (floor, wall, door, railing). Same frame in every panel. No hanger bars, clips, or extra shelves. IKEA / Muji catalog light.

The image reads as four mounts. It does not yet prove one shared joint. Say that out loud.

Feedback question

Which seems more valuable: adapting the rack to the space, adapting it to the laundry, or combining both?
