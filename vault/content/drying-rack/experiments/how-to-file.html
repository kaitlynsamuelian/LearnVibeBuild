If you ran a test, or you are about to, it lives here. One card per test. Mockups and slides stay in Making. Watching someone do laundry stays in Research in person.

  1. Copy this file. Name it after the test, like airflow-experiment.html or rod-diameter.html.
  2. Add a card in data.js under experiments. Same id as the filename. Put the status in the blurb: plan, running, or done.
  3. When you have results, edit the same file. Do not start a second card for the same test unless it is a new question.

The question

One sentence. What would a yes or a no change?

What you built

Materials, sizes, how it was powered. Photo if you have one.

How you ran it

  • What you compared (need a control)
  • What you measured
  • Room conditions if they matter (fan, heat, humidity)

What happened

Empty until you run it. Then numbers, photos, what failed.

What this means

Empty until you run it. Then one paragraph. Do not upgrade a plan into a finding.
