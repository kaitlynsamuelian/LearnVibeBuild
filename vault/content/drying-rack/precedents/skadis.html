IKEA SKÅDIS is a pegboard with a shared connection language (the holes). You keep the board and change what plugs into it, or where that board lives.

What it proves

One core plus one interface can serve different rooms. That is the system logic we are borrowing.

What it does not do

It is for light objects, usually on a wall. It is not a drying rack. Faculty who know SKÅDIS will call that out if we overclaim.

Say it this way

SKÅDIS is the precedent for a system with one core and a shared connection. We are asking whether that idea can work for a drying rack, same frame, different install, not whether we should copy a pegboard.
