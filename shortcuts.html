Keyboard Shortcuts

You don't need to memorize these — but a handful will quickly become second nature. Cmd is the Mac key; on Windows and Linux it's Ctrl.

Shortcuts can change and can be customized. If one doesn't work, open the Command Palette (Cmd/Ctrl + Shift + P), search for the action by name, and it'll show the current key. You can also rebind anything in Settings → Keyboard Shortcuts.
