The Desktop App (the IDE)

This is Cursor as most people know it: a full editor on your Mac, Windows, or Linux computer, with the AI chat, Tab, and everything else built in. If you're just starting, this is your home base — the rest of this page is "good to know," not "must do."

  • Everything from the Features page lives here.
  • Works offline for editing; AI features need an internet connection.
  • Supports the same extensions as VS Code.

The Terminal — commands, with an AI safety net

The terminal is a text box where you type commands to run programs — install tools, start your website, and so on. It sounds intimidating, but Cursor makes it approachable.

Press Cmd/Ctrl + K inside the terminal and describe what you want in English — Cursor writes the exact command for you. And when the Agent needs to run something, it does it here (asking first).

Never memorized a single terminal command? That's fine — ask the AI for it, read what it suggests, then run it.

// For later

Cursor CLI — the agent in your command line

The Cursor CLI (a tool you run by typing cursor-agent) lets you use Cursor's AI agent outside the app — straight from a terminal, a script, or an automated pipeline. It's the same agent, without the graphical window.

Most beginners won't need this on day one. It becomes useful when you want to automate tasks or run Cursor as part of a larger workflow. Good to know it exists.

Think of the CLI as "Cursor's agent you can call from anywhere." File it under things to explore once you're comfortable.

Cloud Agents — tasks that run in the background

Cloud Agents (previously called "Background Agents") run on Cursor's servers rather than your laptop. You hand off a task and it works remotely, in parallel, even after you close your computer. You come back to a finished result to review.

They're great for longer jobs you don't want to babysit — and you can launch and check on them from the web or your phone, not just the desktop app.

Naming note: you may still see "Background Agents" in older tutorials — it's the same idea, now called Cloud Agents.

// Automated review

Bugbot — a second pair of eyes on your changes

Bugbot is Cursor's automated code reviewer. When you propose changes (typically in a pull request on GitHub), Bugbot reads them and flags likely bugs, mistakes, and risky spots — like a careful teammate reviewing your work before it ships.

It's most useful once you're collaborating or working on something real. As a beginner, just know Cursor can help check code, not only write it.

Power-ups: Rules, Skills, Hooks & MCP

You'll hear these words in the Cursor community. You don't need any of them to start — but here's a one-line explanation of each so they stop being mysterious.

Rules

Standing instructions you give the AI for a project — e.g. "always use British spelling" or "prefer this style." Saved as files (like .cursor/rules or AGENTS.md) so the AI remembers them every time.

Skills

Reusable, packaged abilities you can invoke to do a specific task a certain way. (Skills replaced the older "Commands" feature and now also power custom modes.)

Hooks

Automations that run at certain moments — for example, "run the formatter every time the agent finishes editing." They let you wire custom behavior around the agent's actions.

MCP (Model Context Protocol)

A standard way to connect Cursor to outside tools and data — your database, a design tool, an issue tracker — so the AI can use them. Think "plugins for the agent."

Don't feel behind. These are advanced conveniences. Focus on Tab, Ask, and Agent first — you can grow into the rest whenever you're curious.
