First, what are we working with?

Cursor is an AI code editor. Let's unpack those three words, because they tell you almost everything.

"AI"

A smart assistant you talk to in plain English. It can read your work, answer questions, and write code for you.

"Code"

The instructions that make software run. You'll see it, but Cursor can write and explain it, so you don't have to be an expert.

"Editor"

An app for writing and organizing files — like a word processor, but for building websites, apps, scripts, and more.

Familiar under the hood. Cursor is built on VS Code, one of the world's most popular editors. If you've used VS Code, everything is where you expect. If you haven't, no problem — that's what the Interface tour is for.

Download & install Cursor

If you've already installed it, skip ahead to signing in.

Go to the official site

Open cursor.com in your browser and click the Download button. The site detects your operating system (macOS, Windows, or Linux) automatically.

Run the installer

On Mac: open the downloaded file and drag the Cursor icon into your Applications folder. On Windows: double-click the .exe and follow the prompts. It only takes a minute.

Open Cursor

Launch it like any other app. You'll be greeted by a welcome screen the first time. Don't worry about getting everything perfect — you can change any setting later.

Only download from cursor.com. Avoid unofficial mirrors or random links. The official site is the safe place to get Cursor.

Sign in (or create an account)

The AI features run in the cloud, so Cursor asks you to sign in. On the welcome screen, click Sign In — it opens your browser where you can create a free account or log in with Google/GitHub.

  • A free plan lets you try Cursor right away, with a limited amount of AI usage.
  • Paid plans (Pro and up) unlock more usage and access to more powerful AI models.
  • After signing in, your browser hands you back to the app automatically.

Pricing and plan limits change over time. Check cursor.com/pricing for today's exact details.

Coming from VS Code? Import everything in one click

If you already use VS Code, Cursor can copy your setup so it feels like home. If you've never used VS Code, you can safely skip this — Cursor works great with its defaults.

One-click import

During setup, Cursor offers to bring over your VS Code extensions, themes, and keyboard shortcuts. Click it and you're instantly at home.

Do it later if you missed it

Not prompted? You can trigger the import anytime from the settings. Extensions can also be installed individually from the Extensions panel.

Open your first project

In Cursor, you don't open a single file — you open a folder. That folder is your project (developers call it a repository). Everything inside it becomes context the AI can use.

Choose "Open Project" (or "Open Folder")

From the welcome screen or the File menu, pick a folder on your computer. Have nothing yet? Create a new empty folder anywhere and open that — a blank canvas is perfectly fine.

Trust the folder

Cursor may ask if you trust the authors of the files. For your own folders, click Yes, I trust. This is just a safety check.

Let it index (a one-time step)

Cursor quietly reads and "indexes" your files so the AI understands your project. For a new empty folder this is instant. You'll learn more about this on the Features page.

Try your very first request

Now the fun part. Open the AI chat panel (there's a button on the right side, or press the shortcut on the Shortcuts page). Then just type a request in plain English and hit Enter.

Try something like:

"Create a simple webpage that shows my name in a big heading with a nice background color."

Cursor will propose the files and changes. Review what it suggests, then click Accept. Congratulations — you just built something with AI.
