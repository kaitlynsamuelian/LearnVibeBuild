For people who only know ChatGPT / Claude / Cursor

There are other AIs. You can try them this afternoon.

This is a calm guide to open-source and local AI tools — the ones you can inspect, run yourself, or use without sending every message to a big company. It will not pretend they are “free ChatGPT.” It will show you how to actually try them.

Try a chat (no install) First: what “open” means
The honest version

This is not a replacement pitch.

ChatGPT, Claude, and Cursor are good at what they do. Open tools are usually weaker, slower to set up, and more private. You try them because you want to see the insides, keep work on your laptop, or stop paying a subscription for every draft.

“Open” is three different things. Open software (you can read the code), open weights (you can download the model), and local (it runs on your machine). A site can be one of those and not the others. We unpack that next.

Three ways to try, in order

1. Browser chat

No install. Talk to an open model in HuggingChat. Feel the difference from ChatGPT in ten minutes.

2. On your laptop

Ollama (or LM Studio if you want a window, not a terminal). Your files never leave the machine.

3. For code

Point an editor assistant at your local model. Closer to Cursor — not as polished.
