Chapter 3 · one hour, plus a download

Run it on your laptop

This is the privacy path. The model file lives on your disk. Chat does not need the internet after that (except to download the model the first time).

Will your computer survive this?

8 GB RAM

Possible with a small model (1–3B). It will feel slow and dumber. Fine for a first try.

16 GB RAM

The real starting line. 7–8B models (Llama 3.2, a small Qwen) are usable.

32 GB+

You can run bigger coding models. Still not Claude. Much closer to “I could draft here.”

Apple Silicon Macs (M1 and later) are friendlier than old Intel laptops. Leave 10+ GB of disk free before you pull a model.

Path B — Ollama (recommended)

Ollama is the “Homebrew of local models.” One app, then one terminal command.

  1. Download from ollama.com/download and install. On a Mac, drag it to Applications and open it. A llama in the menu bar means it’s running.
  2. Do not also run ollama serve if the app is already open. That fights itself on port 11434.
  3. Open Terminal and run:
    ollama run llama3.2
    First time, it downloads a few gigabytes. Wait. Then type like a chat.
  4. Exit with /bye or Ctrl+D.
  5. See what you have: ollama list. Browse others at ollama.com/library.

If the command isn’t found: quit Terminal, reopen it, or log out and back in so your PATH updates. Or use LM Studio below and skip the terminal.

Path C — LM Studio (if you hate Terminal)

  1. Download lmstudio.ai.
  2. Use the search/discover tab, pick a small instruct model, download it.
  3. Load it and chat in the window. Same idea as ChatGPT, worse model, on-device.

LM Studio is a friendly app. It’s not as “one command” as Ollama. Either is a valid first local setup. Don’t install both on day one.
