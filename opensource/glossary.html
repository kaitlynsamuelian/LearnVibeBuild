Glossary & FAQ

The words this guide uses, plus the questions people ask after their first local chat feels worse than ChatGPT.

Glossary

Open source

Software whose source code you can read and usually change. Does not automatically mean the AI model is free to download.

Weights / open weights

The trained numbers that make a model work. “Open weights” means you can download that file and run it yourself (license permitting).

Local

Running on your computer, not a company’s server. Privacy win. Hardware cost.

Hosted

Someone else runs the model. HuggingChat is hosted even when the model is open-weight.

LLM

Large language model — the brain that predicts the next words. ChatGPT, Claude, Llama are all LLMs (different ones).

Ollama

An app that downloads and serves models on your machine. The usual first local install.

Inference

The model generating an answer. “Training” already happened. You’re just running it.

Hallucination

A confident wrong answer. Open and closed models both do this. Local ones often do it more.

Context window

How much text the model can see at once. Small local models forget the start of a long chat faster.

Quantization

A compressed model so it fits in RAM. A bit dumber, much smaller. Ollama usually picks this for you.

API

A way for programs to talk to a model. Ollama’s is often localhost:11434. ChatGPT’s is on the internet and usually costs money.

Agent

A setup that can take actions (edit files, run commands), not only chat. Cline and Cursor Agent are this shape.

No terms match. Try “local” or “weights.”
