Chapter 1

What “open” actually means

People say “open source AI” like it’s one product. It’s three different promises. If you mix them up, you’ll think you installed privacy and still sent your homework to a server.

The three layers What this is not Why bother

Three layers

Open software

You can read (and usually change) the app — the chat window, the installer, the editor plugin. Ollama’s app, Aider, Cline: software. ChatGPT’s website: not this.

Open weights

You can download the brain (the model file). Llama, Mistral, Gemma, Qwen, DeepSeek have downloadable versions. GPT-4 and Claude do not.

Local

It runs on your machine. Messages stay here. Needs RAM and disk. Usually worse than the cloud models you already pay for.

A common trap: a pretty “open” chat site that still sends your prompt to a company API. That’s open skin, closed brain. Ask: where does the text go when I hit send?

What this guide is not promising

If you need the same quality as ChatGPT or Cursor Agent, stay there for the hard work. Use open tools to learn, to keep a journal private, or to draft when you’re offline.

  • Not always free forever. Hosted “open model” chats can rate-limit you or add a login.
  • Not always legal to use any way you want. Some model licenses block commercial use. Read the card if it matters.
  • Not “the code is the model.” Open weights are a big file of numbers, not a readable novel.

Why people still try

Privacy

A local model does not need your essay, code, or medical notes to leave the laptop.

Cost / offline

After the download, you can chat on a plane. No per-message bill.

Learning

You see that “AI” is a file + a program. That makes Cursor and Claude less magic and more choosable.

Control

You pick the model. You can delete it. Nobody changes the product under you overnight — except when they do, which we’ll flag.
