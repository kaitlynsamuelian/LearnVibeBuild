Reference

The tool shelf

Not a directory of everything. The ones worth a first weekend. Names and sites change — click through before you depend on a step.

Chat in a browser

HuggingChat

Open-weight models in a normal chat UI. Still hosted. Start here. huggingface.co/chat

Chatbot Arena

Blind A/B of two models. Curiosity, not a daily driver. lmarena.ai

Run locally

Ollama

Best first local install. Terminal + menu-bar app. ollama.com

LM Studio

Same idea with a desktop window. Pick if Terminal scares you. lmstudio.ai

Jan

Another local chat app. Try only if Ollama/LM Studio didn’t click. jan.ai

Open WebUI

A ChatGPT-like website on your machine, usually sitting on top of Ollama. Extra setup. Nice later.

Code

Cline

VS Code / Cursor extension. Can use Ollama. Agent-shaped. github.com/cline/cline

Aider

Terminal pair programmer. Local or paid API. aider.chat

Continue

Used to be the default “open Copilot.” Frozen after acquisition. Tutorials still mention it. Prefer Cline/Aider for new setups.

Cursor / Claude Code

Not open. Still the better tools for finishing work. This guide is the other door, not a loyalty test. See Learn Cursor and Learn Claude.

Model families you’ll see

These are brands of brains, not apps. Ollama/HuggingChat let you pick among them.

Llama

Meta. Common default. Fine general chat.

Qwen

Alibaba. Strong coding sizes. Popular with Ollama + Cline.

Mistral / Gemma / DeepSeek

Other open-weight lines. Try one if your first pick is dull. Don’t collect all of them.
