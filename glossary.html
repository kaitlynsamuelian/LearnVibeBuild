Glossary & FAQ

New tools come with new words. Here's every term you'll bump into, each explained in one plain sentence — plus answers to the questions almost every beginner asks.

Glossary

AI Artificial Intelligence

Software that can perform tasks that usually need human intelligence — like understanding language, answering questions, and writing text or code.

LLM Large Language Model

The "brain" behind AI chat tools. It's trained on huge amounts of text so it can predict and generate human-like language — including code. Cursor uses LLMs to power its features.

Prompt

The message or request you send to the AI. "Write a function that adds two numbers" is a prompt. Clearer prompts get better results.

Context

The information the AI can see when answering — your files, your question, attached docs. More relevant context usually means a better answer.

Context window

The maximum amount of information the AI can consider at once. Very large projects may not fit entirely, which is why pointing it at the right files matters.

Token

A small chunk of text (roughly a few characters or part of a word) that AI models read and count. Usage and limits are often measured in tokens.

Agent

An AI that can take actions on its own toward a goal — reading files, editing code, running commands — not just replying with text. Cursor's Agent is its most powerful mode.

Autocomplete

When the editor predicts and offers to finish what you're typing. In Cursor this is called Tab, and it's smarter than traditional autocomplete.

Inline Edit

Cursor's feature for changing a specific selected piece of code by describing the change in a little box (opened with Cmd/Ctrl + K).

Code / Source code

The written instructions that tell a computer what to do. It's just text, organized into files, following the rules of a programming language.

Programming language

A specific set of words and rules for writing code — like Python, JavaScript, or HTML. Each is suited to different kinds of tasks.

File & Folder

A file holds a piece of your project (like one webpage); a folder groups related files together. Your whole project is one main folder.

Editor / IDE

The app you write code in. IDE ("Integrated Development Environment") is a fancy word for a powerful editor with extra tools built in. Cursor is one.

Extension

An add-on that gives your editor extra abilities — support for a language, a color theme, a helpful tool. Cursor supports VS Code extensions.

Terminal / Command line

A text box where you type commands to run programs directly, instead of clicking buttons. Powerful, and Cursor can write the commands for you.

Command

A single instruction you type into the terminal, like npm install, that tells the computer to do something.

Repository (repo)

A project's folder, especially when its history is tracked by Git. People often say "repo" to mean "the whole project."

Git

A widely used system that saves snapshots of your project over time, so you can track changes, undo mistakes, and collaborate. The professional "save history."

GitHub

A popular website for storing Git repositories online, sharing them, and working with others. Git is the tool; GitHub is a place to host it.

Commit

A saved snapshot of your project in Git, with a short note describing what changed. Like hitting "save version" with a label.

Pull request (PR)

A proposal to add your changes into a shared project, so others (or Bugbot) can review them before they're merged in.

Diff

A side-by-side or highlighted view of what changed — green for added lines, red for removed. Cursor shows edits as diffs so you can review them.

Bug

A mistake in code that makes a program behave incorrectly. "Debugging" means finding and fixing bugs — something Cursor can help with.

Checkpoint

An automatic save point Cursor keeps so you can roll back to how things were before an AI request. Convenient, but not a replacement for Git.

Indexing

Cursor quietly reading and mapping your project so the AI can find relevant files quickly. It happens in the background.

Model

A specific AI "brain" you can choose in Cursor. Different models trade off speed, depth, and cost. Beginners can stick with the default.

Rules

Standing instructions you save so the AI follows your preferences on every request in a project (e.g. coding style). Stored in files like .cursor/rules or AGENTS.md.

Skill

A packaged, reusable ability you can invoke to do a task a certain way. Skills also power Cursor's custom modes.

Hook

An automation that runs at a specific moment — for example, formatting your code every time the agent finishes editing.

MCP Model Context Protocol

A standard way to connect Cursor's AI to outside tools and data (databases, design apps, trackers). Think "plugins for the agent."

Cloud Agent

An agent that runs on Cursor's servers instead of your computer, so it can keep working in the background even after you close the app. Formerly "Background Agent."

Bugbot

Cursor's automated code reviewer that reads your proposed changes and flags likely bugs and issues before they ship.

Hallucination

When an AI states something incorrect or made-up with confidence. It's why you always review AI output rather than trusting it blindly.

Localhost

Your own computer acting as a mini web server. When you run a website locally you'll often visit an address like localhost:3000 to preview it.
