The one-minute version

So, what actually is Cursor?

Cursor is a code editor — the kind of app programmers use to write software — with a powerful AI assistant built right in. Think of it as a document editor for code, except you also have a tireless helper sitting next to you that can explain things, write code for you, fix mistakes, and even carry out whole tasks on your behalf.

It's built on top of a popular editor called VS Code, so it feels familiar to many developers — but you don't need to know any of that. You can simply describe what you want in plain English, and Cursor helps make it happen.

No experience required. Every page here assumes you're starting from zero. We explain the words as we go, and there's a Glossary & FAQ for anything unfamiliar.

Why people love it

It's a normal editor — plus a helper that never gets tired

Here are the ideas that make Cursor click for new users. Don't worry about memorizing them; you'll meet each one hands-on later.

Autocomplete on steroids

As you type, Cursor predicts your next edit and offers to write it for you. Accept with a single key. This is called Tab.

Just ask, in English

Open the chat and type what you want — a question, a change, a whole feature. The Agent can read your files and make the edits.

You're always in control

Cursor proposes changes; you review and approve them. Nothing is final until you say so, and you can undo anything.

The big idea

Three ways the AI helps, and when to use each

New users mix these up constantly. Here's the quick mental model — the Features page covers each in depth.

Tab

Finishes the line or edit you're already making, right where your cursor is. Silent, instant, no chatting.

Use when: you're typing and want a quick suggestion.

Inline Edit

Select some code (or an empty spot), press a shortcut, and describe a change to that exact spot.

Use when: you want to tweak one specific piece.

Agent (Chat)

A full conversation. Describe a goal and the agent can read, plan, edit multiple files, and run commands for you.

Use when: you want the AI to actually do a task.
